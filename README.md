## Overview

The Eagle SAM D11C Development Board was designed and developed as a custom PCB to meet specific embedded development and prototyping requirements. The board features a compact custom form factor with an integrated RGB LED for visual feedback and debugging.


![Hero Image](/assets/milling_db_side_pic_12.jpg)

Power is supplied through a USB Type-C connector, and the board exposes 5V, GND, and digital I/O pins for interfacing with external components and peripherals. The PCB was designed as a double-layer board in KiCad and fabricated using a Roland RDX milling machine.

## PCB Design

The board was designed in KiCad as a double-layer PCB to improve routing flexibility and overall reliability. Special attention was given to:

* Compact board layout
* Signal routing
* Component placement
* USB Type-C integration
* Power distribution
* Manufacturability

## Fabrication Process

![machine](/assets/Roland_milling_machine_pic.jpg)

The PCB fabrication workflow involved:

* PCB schematic and layout design in KiCad
* Toolpath generation for PCB milling
* Double-layer PCB milling using Roland RDX
* Soldering and component assembly
* Electrical testing and validation
